# Antenna Parameter Calculator

### Developed by **Devavrat Rajendra Choure**

This Python-based GUI application calculates and plots antenna parameters such as wavelength, gain, and bandwidth.  
It uses Tkinter for the graphical interface and Matplotlib for plotting Gain vs Frequency.

#### Features:
- Calculate wavelength, gain, and bandwidth.
- Plot Gain vs Frequency (1–10 GHz).
- Simple GUI built with Python 3.

#### Run:
```bash
python antenna_calculator.py
